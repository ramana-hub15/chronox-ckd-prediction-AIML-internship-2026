About ChronoX

ChronoX is a full-stack clinical machine learning application built to demonstrate transparent, calibrated Chronic Kidney Disease risk screening with an accessible, mobile-first PWA interface.

ML Pipeline

Trained on {{ metrics.dataset.source }} using an 80/20 stratified split and 5-fold stratified cross-validation.

  • Median / mode imputation inside Scikit-learn ColumnTransformer
  • Quantile winsorization (ClinicalOutlierClipper) fit exclusively on training folds
  • StandardScaler feature normalization
  • 5-fold sigmoid calibration via CalibratedClassifierCV
Security & Stack
  • Flask 3.1 application factory with Blueprints & SQLAlchemy ORM
  • Werkzeug salted password hashing, CSRF protection, and HTTPOnly cookies
  • Flask-Limiter brute-force protection on authentication routes
  • REST API endpoints: /api/predict, /api/metrics, /api/history
